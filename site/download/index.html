Install
  1. Run the installer you downloaded.
  2. Windows SmartScreen may say Windows protected your PC. FCMS Pro is not code signed, so this is expected. Click More info, then Run anyway.
  3. Follow the setup, then open FCMS Pro. The first-run setup shows you where your data folder is.

Install
  1. Open the .dmg and drag FCMS Pro into Applications.
  2. The app is not signed with an Apple Developer ID, so Gatekeeper may refuse a normal double-click.

  4. On macOS 15 or newer that right-click shortcut no longer works. Try to open the app once, then go to System Settings → Privacy & Security, scroll to the message about FCMS Pro and click Open Anyway.

If the AppImage will not start, your distribution may be missing libfuse2 (newer Ubuntu releases no longer include it) or the ICU libraries (libicu). Install them with your package manager, or use the .deb instead.

Verify your download

FCMS Pro is not code signed, so the SHA-256 checksum is how you confirm the file is the one that was published. The values above come from the GitHub Release, which also carries them as SHA256SUMS.txt. The two must match.

# Windows (PowerShell)
Get-FileHash -Algorithm SHA256 .\{{asset.windows.name}}

# macOS
shasum -a 256 {{asset.macos.name}}

# Linux
sha256sum {{asset.linux_deb.name}}
Back up before you update. Your database lives in your user data folder, not next to the program, so updating does not replace it. On Windows, uninstalling does delete that folder. FCMS Pro stores everything locally with no cloud copy, so export a backup from the Backup page first.
