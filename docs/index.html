Features

Everything a solo freelancer needs to stay on top of the money, in one place.

Native & Fast

Built with Avalonia UI and .NET 8, so it runs as a real desktop app on Windows, macOS and Linux instead of a web page in disguise.

Local & Private

Your clients and finances are yours. Everything lives in a SQLite file on your own computer. No account, no server, no telemetry.

Financial Tracking

Track commissions, payments and expenses with automatic balances, overdue and due-soon warnings, and income analytics.

Client Management

Keep client details, notes, attachments and full commission history together in one profile.

Recurring Commissions

Set a repeat frequency (weekly, monthly) and the next commission is created automatically when the current one is delivered.

Backups You Control

Automatic local backups with a retention count you choose, plus manual export and import of your whole database.

FAQ

Where is my data stored?

In a SQLite file on your own computer. There is no server, no account and no telemetry. That also means backups are your responsibility, so use the built-in backup and export regularly.

Does it work on an Intel Mac?

The current macOS download is built for Apple Silicon (M1 or newer) only. If you need an Intel build, please open an issue.

Why does my system show a security warning?

The app is not code signed, because that needs a paid certificate. Windows SmartScreen and macOS Gatekeeper both warn about unsigned apps. Follow the steps in the note near the download buttons, and only download from this site or the GitHub Releases page.

How do updates work?

FCMS Pro checks GitHub for a newer version when it starts and offers to install it. You can always download the newest installer from the buttons above. The full history is in the changelog.

I found a bug or want a feature.

Please use GitHub Issues. You can also reach the author on Messenger using the button at the bottom right (or the footer link).
