Lightning Fast UI

Built with Avalonia UI for native performance. FCMS Pro launches instantly and handles thousands of records without a sweat.

Local & Private

Your clients and finances are yours. All data is securely stored locally in an offline SQLite database. No cloud accounts required.

Financial Tracking

Manage commissions, generate quotes, track payments and expenses, and issue PDF receipts and invoices with ease.

Client Management

Keep track of client details, notes, and full commission history all in one centralized profile.

Recurring Commissions

Set repeat frequencies (weekly, monthly) to automatically spawn new commissions when the current one is delivered.

Atomic Backups

Never lose your work. Effortlessly export automated backup snapshots of your entire database with a single click.

How to Get Started

1

Download & Extract

Download the latest release for your operating system using the buttons above. Extract the ZIP file to a folder of your choice.

2

Run the Application

Inside the extracted folder, double-click the FcmsPro executable. No installation required — it runs completely standalone.

3

Onboarding Tour

When you launch the app for the first time, an interactive onboarding tour will guide you through creating your first client and tracking a commission.
